Getting Started

AI Security Copilot helps security teams analyze security reports, identify vulnerabilities, and review AI-assisted remediation recommendations.

Analyze a Report

Follow these steps to analyze a security report.

1

Open Analyze Report

Navigate to the Analyze Report page from the dashboard.

2

Upload your report

Choose a file or drag and drop it into the upload area.

3

Verify the file

Make sure the report uses a supported format and is within the maximum file size.

4

Start analysis

Start the analysis process and review the resulting security findings.

Supported Formats

The application currently supports the following report formats.

Format Description
PDF Security assessment and vulnerability reports
JSON Structured security findings
TXT Plain-text security reports
CSV Tabular security findings

Maximum supported file size: 50 MB

Understanding Findings

Findings represent potential security vulnerabilities identified during report analysis.

Critical

Immediate attention is recommended.

High

Represents a significant security risk.

Medium

Represents a moderate security concern.

Low

Lower-priority issue that should still be reviewed.

AI Remediation

AI Security Copilot provides remediation guidance to help users understand and address identified security vulnerabilities.

  • Vulnerability explanation
  • Potential security impact
  • Recommended remediation
  • Suggested security improvements

Dashboard

The dashboard provides an overview of your security analysis activity and detected findings.

Severity Metrics

Review findings by severity.

Recent Uploads

Review recently analyzed reports.

Security & Privacy

Security reports may contain sensitive information. Always verify that uploaded reports are appropriate for the environment in which the application is being used.

The exact storage, retention, and processing behavior depends on the backend configuration of the application.
